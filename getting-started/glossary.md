| Term | Meaning |
|---|---|
| **A/C** | Aircraft. The fixed action button that toggles the ENG and FLT pages. |
| **ACQ** | Acquisition source: where your sight is cued to and slaves to. |
| **ADU** | Air defence unit, an FCR target class. |
| **APU** | Auxiliary power unit. A small turbine that powers the aircraft and starts the engines. |
| **ASE** | Aircraft survivability equipment: the warning receivers, chaff, flares and IR jammer. |
| **ATM** | Air targeting mode of the FCR. |
| **BUCS** | Back-up control system, the fly-by-wire back-up to the mechanical flight controls. |
| **C-SCOPE** | Radar targets shown on the helmet and VIDEO page. |
| **COORD** | Coordinate data page. |
| **CPG** | Copilot/gunner, in the front seat. |
| **DMS** | Data management system, the pages for points, routes and aircraft data. |
| **DTV** | Day TV, the TADS black and white camera. |
| **DVO** | Direct view optics, the TADS colour daylight optic. |
| **FAB** | Fixed action button: the labelled buttons on an MPD bezel (FCR, WPN, TSD, A/C, COM, VID, M). |
| **FCR** | Fire control radar, the Longbow radar above the rotor. |
| **FLIR** | Forward looking infrared: a thermal camera. Both the TADS and the PNVS have one. |
| **FMC** | Flight management computer: the stability augmentation and hold modes. |
| **FOV** | Field of view: W(ide), M(edium), N(arrow), Z(oom). |
| **GTM** | Ground targeting mode of the FCR. |
| **HAD** | High action display: the status lines at the bottom of the helmet and TADS symbology. |
| **HDU** | Helmet display unit, the monocle in front of your right eye. |
| **HMD** | Helmet mounted display; also the helmet sight. |
| **IAFS** | Internal auxiliary fuel system, a tank that replaces the 1,200 round cannon magazine. |
| **IHADSS** | Integrated helmet and display sight system. |
| **KU** | Keyboard unit, for entering data. |
| **LMC** | Linear motion compensator: keeps the TADS moving with a moving target. |
| **LOAL / LOBL** | Lock-on after launch / lock-on before launch. |
| **LOS** | Line of sight. |
| **LRFD** | Laser rangefinder/designator, in the TADS. |
| **LST** | Laser spot tracker, in the TADS. |
| **MPD** | Multipurpose display, the two square screens in each crew station. |
| **Ng** | Gas generator speed of an engine, percent. |
| **Np** | Power turbine speed of an engine, percent. |
| **Nr** | Main rotor speed, percent. |
| **NTS** | Next to shoot: the radar target the next radar-guided missile will be fired at. |
| **NVS** | Night vision system: whichever sensor gives you a night picture on the monocle. |
| **PFZ / NFZ** | Priority fire zone / no fire zone. |
| **PLT** | Pilot, in the rear seat. |
| **PNVS** | Pilot night vision sensor, the FLIR turret on top of the nose. |
| **RF** | Radio frequency: the radar-guided Hellfire (AGM-114L). |
| **RLWR** | Radar and laser warning receiver. |
| **RMAP** | Radar map mode of the FCR. |
| **SAL** | Semi-active laser: the laser-guided Hellfire (AGM-114K and others). |
| **SFR** | Specific fuel range. |
| **TADS** | Target acquisition designation sight, the large turret under the nose. |
| **TGT** | Turbine gas temperature, °C. |
| **TPM** | Terrain profile mode of the FCR. |
| **TSD** | Tactical situation display, the moving map page. |
| **UFD** | Up-front display, the small screen above the right MPD. |
| **VAB** | Variable action button: the 24 unlabelled buttons around each MPD. Named by side and number: T1–T6, B1–B6, L1–L6, R1–R6. |
| **WAS** | Weapon action switch: choosing which weapon your crew station fires. |
| **WCA** | Warnings, cautions and advisories. |
