| Term | Meaning |
|---|---|
| A/C | Aircraft. The fixed action button that selects the ENG and FLT pages. |
| ACQ | Acquisition source: the line of sight to which the selected sight is cued and slaved. |
| ADU | Air defence unit; an FCR target class. |
| ANTS | Alternate next-to-shoot: the second priority FCR target. |
| APU | Auxiliary power unit. Provides electrical, hydraulic and pneumatic power for engine start. |
| ASE | Aircraft survivability equipment: warning receivers, chaff, flares and IR jammer. |
| ATM | Air targeting mode of the FCR. |
| AWS | Area weapon system: the M230 chain gun, its turret and the ammunition handling system. |
| BUCS | Back-up control system. |
| C-SCOPE | FCR target symbols presented on the flight and weapon symbology formats and the VIDEO page. |
| CAQ | Cursor acquisition: selection of the acquisition source on the TSD with the MPD cursor. |
| COM | Communications: the fixed action button and page for radio presets and tuning (not simulated). |
| COORD | Coordinate data page. |
| CPG | Copilot/gunner, front crew station. |
| DE | Dual engine. |
| DEC | Digital electronic control: each engine's control, which governs Np and limits TGT. |
| DMS | Data management system: pages for data transfer, advisories, faults, warnings, cautions and software versions. |
| DTC | Data transfer cartridge: mission data built in the mission planner and loaded with MASTER LOAD. |
| DTV | Day TV: the TADS monochrome television sensor. |
| DVO | Direct view optics: the TADS colour optical sight. |
| EA | Engagement area, displayed on the TSD as EA01 to EA12. |
| EMER HYD | Emergency hydraulics: applies utility accumulator pressure to the flight controls on a loss of both hydraulic systems. |
| ETL | Effective translational lift, 16 to 24 kt. |
| FAB | Fixed action button: the MPD subsystem buttons (FCR, WPN, TSD, A/C, COM, VID). |
| FCR | Fire control radar. |
| FLIR | Forward looking infrared: a thermal sensor. The TADS and the PNVS each have one. |
| FLOT / FLET | Forward line of own troops / forward line of enemy troops. |
| FMC | Flight management computer: stability augmentation and hold modes. |
| FOR | Field of regard: the limits of travel of a sensor. |
| FOV | Field of view: W(ide), M(edium), N(arrow), Z(oom). |
| FRZ | Freeze: holds the TSD map stationary. |
| FSCL | Fire support coordination line. |
| GRBX | Gearbox: a nose gearbox (GRBX1, GRBX2), or the intermediate and tail rotor gearboxes (GRBX VIB). |
| GTM | Ground targeting mode of the FCR. |
| HAD | High action display: the status message fields along the bottom of the flight and weapon symbology formats. |
| HDU | Helmet display unit, in front of the crewmember's right eye. |
| HMD | Helmet mounted display; also the helmet sight. |
| HMU | Hydromechanical unit: the engine's fuel control, in its accessory section. |
| IAFS | Internal auxiliary fuel system ("Robbie"): a 663 lb fuel cell in the ammunition bay. |
| IAT | Image auto track: holds the TADS on a target. |
| IGE / OGE | In ground effect / out of ground effect. |
| IHADSS | Integrated helmet and display sight system. |
| KU | Keyboard unit, for data entry. |
| LMC | Linear motion compensator: maintains TADS motion on a moving target. |
| LOAL / LOBL | Lock-on after launch / lock-on before launch. |
| LOS | Line of sight. |
| LRFD | Laser rangefinder/designator, in the TADS. |
| LST | Laser spot tracker, in the TADS. |
| MPD | Multipurpose display; two in each crew station. |
| Ng | Gas generator speed, percent. |
| Np | Power turbine speed, percent. |
| Nr | Main rotor speed, percent. |
| NTS | Next-to-shoot: the highest priority FCR target, assigned to the next RF Hellfire. |
| NVS | Night vision system: the sensor providing night vision video on the HDU. |
| OFS | Offset: moving the TADS about a target tracked by the IAT. |
| PFZ / NFZ | Priority fire zone / no fire zone. |
| PLT | Pilot, rear crew station. |
| PNVS | Pilot night vision sensor: the FLIR turret on top of the nose. |
| RF | Radio frequency: the radar-guided Hellfire (AGM-114L). |
| RLWR | Radar and laser warning receiver. |
| RMAP | Radar map mode of the FCR. |
| SAL | Semi-active laser: the laser-guided Hellfire. |
| SE | Single engine. |
| SFR | Specific fuel range. |
| SWARM | Engagement sequence: Sight, Weapon, Armed, Range, Messages. |
| SWP | Settling with power: a rate of descent that cannot be arrested with the engine power available. |
| TADS | Target acquisition designation sight: the turret under the nose. |
| TGT | Turbine gas temperature, °C. |
| TPM | Terrain profile mode of the FCR. |
| TRP | Target reference point: the centre of four PF zones made on the ZN page. |
| TRU | Transformer rectifier unit: converts AC from the generators to DC. Two are installed. |
| TSD | Tactical situation display. |
| UFD | Up-front display. |
| VAB | Variable action button: the 24 MPD bezel buttons, T1–T6, B1–B6, L1–L6, R1–R6. |
| VNE | Velocity never exceed. |
| VRS | Vortex ring state: an aerodynamic stall of the main rotor caused by an excessive vertical rate of descent. |
| VSSE | Velocity safe single engine. |
| WAS | Weapon action switch: selects the weapon for the crew station. |
| WCA | Warnings, cautions and advisories. |
| XMSN | Main transmission. |
| ZN | TSD zone page, for priority fire and no fire zones. |
