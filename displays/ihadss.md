## Flight symbology

The pilot and the CPG each get their own symbology, drawn in green on the helmet display unit (HDU) monocle. With the monocle stowed you see nothing, so the first thing to do after strapping in is to [fit the HDU]({{ '/aircraft/cockpit/' | relative_url }}#hdu).

There are four flight modes. Select them with the symbology select switch:

| Binding | Mode |
|---|---|
| {% include key.html id="fza_ah64_symbologySelectUp" %} | Toggles **transition** and **cruise**. |
| {% include key.html id="fza_ah64_symbologySelectDown" %} | Toggles **hover** and **bob-up**. Entering bob-up stores your current position and heading. |
