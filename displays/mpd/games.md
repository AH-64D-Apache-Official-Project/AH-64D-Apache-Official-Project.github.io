> The MPD games are a mod feature and are not part of the aircraft's systems. They are reached through the IBIT button.
{: .note}

The game list is selected from the [DMS pages]({{ '/displays/mpd/dms/' | relative_url }}) or the [WCA page]({{ '/displays/mpd/wca/' | relative_url }}) with `T3`{: .vab} IBIT.

| Button | Game | Players |
|---|---|---|
| `L1`{: .vab} | Asteroids | 1 |
| `L2`{: .vab} | Space Invaders | 1 |
| `L3`{: .vab} | Breakout | 1 |
| `L4`{: .vab} | Lunar Lander | 1 |
| `R1`{: .vab} | Pong | 1 against the computer, or 2 |
| `R2`{: .vab} | Battleship | 1 against the computer, or 2 |
| `R3`{: .vab} | Tic Tac Toe | 1 against the computer, or 2 |
| `R4`{: .vab} | Connect 4 | 1 against the computer, or 2 |
| `R5`{: .vab} | Rock Paper Scissors | 1 against the computer, or 2 |
| `R6`{: .vab} | Checkers | 1 against the computer, or 2 |
| `B1`{: .vab} | Return to DMS | |

`B2`{: .vab} DOOM is displayed when the separate AH-64D Doom addon is loaded.

## Controls

The game inputs are bound in **Options → Controls → AH-64D MPD Minigames**: up, down, left, right and fire. The keyboard does not reach the game directly; only these bindings do.

While a game is open, the bottom row operates the game:

| Button | Function |
|---|---|
| `B1`{: .vab} | Game list |
| `B2`{: .vab} | Game-specific control, for example rotating a ship in Battleship |
| `B4`{: .vab} | Restart |
| `B5`{: .vab} | Pause or resume |
| `B6`{: .vab} | Sound on or off, for all games |

## Two players

Two-player games pair the two crewmembers of the same aircraft. Opening the same game on an MPD in each crew station starts a match. If one player leaves the game page, the match waits for that player to return. Returning to the game list with `B1`{: .vab} leaves the match.

## Scores

Best scores are kept in the player's Arma profile and carry over between missions and servers. Each game also displays the server's top ten, and the two-player games keep a win and loss record.
